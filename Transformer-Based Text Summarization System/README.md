# Transformer-Based Text Summarization System
Notebook that fine-tunes `t5-large` with the Hugging Face `Trainer` on the SAMSum dialogue dataset (train and validation CSVs), after cleaning the text.

**Run:** `pip install transformers datasets pandas torch`, add the SAMSum CSVs, update the paths in the notebook, run all cells. Dataset files are not in the repo.
No evaluation scores are claimed because none are in the notebook.
